# Bloco Prompt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Inserir prompts no Sanity e permitir copiar seu texto no blog.

**Architecture:** Adicionar um objeto `prompt` ao array Portable Text existente. Renderizar somente esse bloco com um componente cliente, mantendo o restante do artigo no servidor. Preservar seu conteúdo no RSS e no texto usado para tempo de leitura.

**Tech Stack:** Next.js 15, React 19, JavaScript, Sanity Studio 6, CSS existente, Clipboard API.

**Spec:** `docs/superpowers/specs/2026-11-11-prompt-design.md`

## Global Constraints

- Bloco separado Prompt, título opcional e texto obrigatório.
- Rótulo padrão Prompt; botão Copiar prompt; sucesso Copiado!.
- Copiar somente o texto original, preservando quebras de linha.
- Sem dependências novas; não modificar conteúdo publicado para testar.
- Deploy do blog e do Studio são necessários para disponibilizar a funcionalidade nos respectivos ambientes.

## Review Focus

- Falha ou ausência da Clipboard API: mensagem acessível, nova tentativa e seleção manual disponíveis.
- Vários prompts: copiar somente o texto da caixa acionada.
- Texto longo e URLs: quebra de linha sem rolagem horizontal na página móvel.
- Caracteres HTML e linhas vazias: exibir como texto e preservar a cópia literal.
- Título ausente e texto vazio legado: rótulo Prompt e omissão de blocos vazios.
